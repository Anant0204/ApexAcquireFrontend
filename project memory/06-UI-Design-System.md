# UI Design System & Theme

## Visual Identity: Luxury Obsidian & Sapphire Theme
The application adopts a premium, executive aesthetic to match the target audience (real estate acquisitions desk).

### Colors
- **Backgrounds:**
  - App Background: Soft off-white/gray `#F8FBFF`
  - Sidebar: Deep Obsidian/Dark Blue `#0B1533` to `#0B1F3A`
  - Cards: Pure White `#FFFFFF`
- **Accents:**
  - Primary Brand (Sapphire): `#155EEF`
  - Highlights / Glows: `#60A5FA` / `#93C5FD`
  - Badges / Urgent: Rose/Red `#E11D48`
  - Badges / Success: Emerald `#34D399`

### Typography
- **Font Family:** Modern Sans-serif (e.g., Inter, Outfit)
- Emphasis on tight tracking for headers and extreme clarity for data tables.

### Micro-Interactions & Styling
- **Glassmorphism:** Used sparingly in sidebar active states and alerts (e.g., `backdrop-blur-sm`).
- **Glow Effects:** Active states in the sidebar feature subtle blue glow shadows `shadow-[0_0_12px_rgba(147,197,253,0.9)]`.
- **Borders & Radii:** Extensive use of rounded corners (xl, 2xl) and subtle, light borders (`#E2EAF5`) to segment UI elements without heaviness.
