# Database Schema

## 1. Users
- `id` (UUID, Primary Key)
- `email` (String, Unique)
- `name` (String)
- `role` (Enum: ADMIN, MANAGER, AGENT, READ_ONLY)
- `status` (Enum: ACTIVE, INACTIVE)

## 2. Contacts (Realtors)
- `id` (UUID, Primary Key)
- `first_name` (String)
- `last_name` (String)
- `license_number` (String, Indexed)
- `brokerage` (String)
- `email` (String, Indexed)
- `phone` (String, Normalized, Indexed)
- `is_mobile_capable` (Boolean)
- `market` (String, Default: 'DFW')
- `status` (Enum: Active in Outreach, Responded, Escalated, Declined, Opted Out, Do Not Contact)
- `source` (String)
- `cadence_start_date` (Timestamp)
- `last_contacted_date` (Timestamp)
- `last_response_date` (Timestamp)
- `owner_id` (UUID, Foreign Key -> Users)
- `tags` (Array of Strings)

## 3. Interactions & Conversations
- `id` (UUID, Primary Key)
- `contact_id` (UUID, Foreign Key -> Contacts)
- `channel` (Enum: SMS, EMAIL, CALL, NOTE)
- `direction` (Enum: INBOUND, OUTBOUND, SYSTEM)
- `message_body` (Text)
- `timestamp` (Timestamp)
- `actor_id` (UUID, Foreign Key -> Users or 'SYSTEM'/'AI')
- `ai_classification` (String)

## 4. Deals & Properties
- `id` (UUID, Primary Key)
- `property_address` (String, Normalized, Indexed)
- `city` (String)
- `state` (String)
- `zip` (String)
- `asking_price` (Decimal)
- `condition` (String)
- `timeline` (String)
- `contact_id` (UUID, Foreign Key -> Contacts)
- `owner_id` (UUID, Foreign Key -> Users)
- `pipeline_source` (Enum: MANUAL, AI_INBOUND)
- `stage` (Enum: New Property, Qualifying, Offer Made, Offer Accepted, Offer Rejected, Trash, Duplicate Lead, Need Help)
- `loss_reason` (String)

## 5. Tasks
- `id` (UUID, Primary Key)
- `type` (Enum: Needs Human Touch, Manager Escalation, Lead Clone, General)
- `assigned_to` (UUID, Foreign Key -> Users)
- `related_contact_id` (UUID)
- `related_deal_id` (UUID)
- `due_date` (Timestamp)
- `status` (Enum: PENDING, COMPLETED)
